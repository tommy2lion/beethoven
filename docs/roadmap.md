# 实现路线图

> 以下是分阶段实现 Beethoven 项目的路线图。每一阶段都有明确目标、可交付成果和衡量标准，按难度递增。

**核心原则**：
- **先跑通，再优化**——第一个版本无论多粗糙，跑通整个 pipeline 比追求 SOTA 重要
- **先听懂，再写代码**——每进入一个新阶段，先运行现有工具（Demucs、Spleener 等你的补充）感知结果
- **能听、能看、能量化**——每个阶段结束后，你能"听"到分离结果、"看"到频谱图、"量"到 SDR 分数

```bash

音乐多乐器声源分离的技术构想
 
在音频与音乐信号中，一首完整的乐曲通常由多种乐器的声波信号叠加融合而成。混合音频的波形本质是各类乐器独立声波的叠加，由此可提出猜想：可通过计算机技术对混合音频波形进行逆向拆解，实现不同乐器声源的独立提取与还原。
 
从信号处理角度分析，连续的音乐波形承载了全部的声音信息。为实现声源拆解，可将整段时长的音频划分为若干极短的时间微元片段，对每一个时刻、每一段短时波形进行独立求解，拆分出该时刻对应的各类乐器基础声波分量，最终得到全时段的声源分解结果。
 
该拆解方式存在核心问题：单一混合波形对应无数组波形分解解，属于典型的多解问题，单纯数学拆解无法得到贴合真实演奏的有效结果。因此，需要为求解过程增设物理与音乐层面的约束条件，筛选合理最优解。
 
核心约束为时序连续性约束：真实乐器的演奏具备自然连续性与规律性，单一乐器在相邻时刻的声波形态、音量、音色不会出现突兀跳变。因此各时刻拆解得到的乐器波形解，必须与前后时刻的分解结果形成时序呼应、平滑衔接，剔除违背自然演奏规律的无效解。
 
在此基础上，可引入人工智能模型优化求解过程。通过让模型海量学习乐谱数据与常规作曲、演奏规律，习得音乐底层逻辑与乐器发声特征，以此作为判别依据，校验波形分解结果的合理性。通过信号拆解、时序约束、乐理先验校验的结合方式，能够大幅提升多乐器声源拆解的准确率，实现乐曲乐器声部与乐谱信息的高精度还原。
```

## 阶段 1：合成数据 + 小实验（2-3 周）

> **目标**：用可控的合成数据验证"从混合信号中分离乐器"这个想法在数学上可行。

### Step 1.1 合成多乐器数据

```python
# 概念脚本：synthesize_data.py
goal = "给定一个 MIDI 文件，渲染为 3 个不同乐器的"湿"音频（钢琴、小提琴、长笛）"
steps = [
    "1. 用 music21 或 midi 库解析 MIDI 文件",
    "2. 用 FluidSynth + GeneralUser GS 音源库渲染为每个乐器独立音轨",
    "3. 导出: mix.wav, piano.wav, violin.wav, flute.wav",
]
```

**推荐使用的库**：
- [`music21`](http://web.mit.edu/music21/)：MIT 开发的音乐分析库，处理 MIDI/乐谱很方便
- [`pyfluidsynth`](https://github.com/nwhitehead/pyfluidsynth)：FluidSynth 的 Python 绑定，可以从 MIDI 合成音频
- **音源库（SoundFont）**：推荐 [GeneralUser GS](https://schristiancollins.com/generaluser.php) 或 FluidR3_GM——免费、音色多

### Step 1.2 用线性方法建立 Baseline

在深度学习之前，先用经典信号处理方法做分离，你会立刻理解"为什么需要深度学习"：

```python
from scipy.signal import wiener

# 维纳滤波：假设乐器在不同频带
# 效果：对非重叠频率的乐器勉强可用，一混叠就彻底失效

from sklearn.decomposition import NMF

# 非负矩阵分解，将频谱分解为"频谱模板 × 时间激活"
# 效果：对频谱结构简单的乐器（如钢琴、吉他）比维纳滤波好
# 但在复杂乐器（如弦乐组）上失效
```

**关键认知要在这个阶段获得**：
- 当两个乐器频率范围不重叠（如贝斯 vs. 三角铁）→ 容易分
- 当两个乐器频率范围重叠（如两把吉他）→ 纯信号处理无法解决 → **需要深度学习**

### Step 1.3 验证你的"时序连续性"直觉

在合成数据上，用以下方式验证你的核心想法：

```python
# 创建"违反时序连续性"的分离结果（每帧独立随机分离）
# → 听感会有很多"咔嚓"爆音和跳跃
# 添加时序平滑（相邻帧取平均）
# → 听感明显改善
```

这个小小的实验会让你深刻理解为什么时序连续性约束如此重要。

**训练要点**：
- **Loss 函数**：L1 Loss 在频谱域 + 可选的时序连续性 Loss

### Step 2.3 训练循环

```python
for epoch in range(100):
    for batch in dataloader:
        mix, targets = batch
        masks = model(mix)              # 预测掩码
        predictions = masks * mix       # 应用到混合频谱
        
        loss_l1 = F.l1_loss(predictions, targets)
        loss_tc = temporal_continuity(masks)
        loss = loss_l1 + 0.1 * loss_tc
        
        loss.backward()
        optimizer.step()
    
    # 每个 epoch 后评估
    sdr = evaluate(model, validation_set)
    print(f"Epoch {epoch}: L1={loss_l1:.4f}, SDR={sdr:.2f}dB")
```

**你的第一次关键瓶颈**：训练初期 loss 下降很慢，别灰心——这是正常的。当 loss 开始下降后，分离质量的"跳跃"会很突然（通常在 20-30 epoch 后）。

尝试以下改进（按优先级排序）：

```python
# ① 增加通道数（16→32→64 vs 8→16→32）
```

## 阶段 4：探索与定制（持续）

> **目标**：做出你自己的贡献——无论是新架构、自定义乐器分离、还是有趣的应用。

### 你特有的优势

- **两种思路的结合**：目前学术界要么做掩码法，要么做生成法，很少有人系统地融合两者。这就是你可能的创新点。
- **你能控制的数据**：如果你喜欢某个特定乐器（如钢琴、古筝），你可以专门优化针对该乐器的分离——小而专注的模型往往比通用大模型在特定场景表现更好。
- **非西方音乐**：目前大多数数据集和模型基于西方音乐。如果你感兴趣民族乐器分离（二胡、琵琶、古筝），这是一个有意义的探索方向——而且需求很强（很多音乐人想从老录音里分离民族乐器）。

### 探索方向

```python
# 方向 1：自定义乐器分离
# 训练一个"钢琴+吉他专用"的二轨分离模型

# 方向 2：可视化工具
# 把你的分离过程做成网页应用，用户上传歌曲→选择乐器→听到分离结果
# 用 gradio 或 streamlit 一天内就能做出来

# 方向 3：MIDI 输出
# 不仅分离乐器，还输出每件乐器的 MIDI 乐谱——"听感识别谱面"
# 这对音乐教育很有价值

# 方向 4：实时分离
# 用模型量化（torch.quantization）和 ONNX Runtime 加速
# 目标是实现实时/低延迟分离
```

## 第一个 Checkpoint：我应该继续吗？

在完成**阶段 1**后，问自己三个问题：

1. **我能从合成音频中分离出不同乐器吗？**（即使效果很一般）
2. **我理解了"为什么纯信号处理不够，需要深度学习"吗？**
3. **我觉得这个过程有趣吗？**

如果三个都是"是"——继续，你会在声源分离上做得很好。
如果第三个是"否"——音频可以换一个方向（如音乐生成、乐器识别、编曲推荐），不必强求分离。

> 最后一条建议：**公开分享你的进展**。把你的合成数据、第一次分离结果（即使很糟糕）、SDR 分数发在 GitHub 或知乎上。一方面别人会给你反馈和鼓励，另一方面这也能帮到你后续做学院工作时的简历。
